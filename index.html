Windows Sandbox

What is it?

A lightweight, isolated and disposable Windows desktop for safely testing apps, files and tools. Close it and its software, files and state are removed.

How do I install it?

On a supported Windows edition, open Turn Windows features on or off, enable Windows Sandbox and restart if prompted.
