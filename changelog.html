V1.0.0 · FIRST PUBLIC RELEASE

Build My Sandbox is ready to play

🧰

Toolbox workflowProvisioning now has a polished live Toolbox with Pending, Installing, Ready and Failed states, direct launch actions, readable failure feedback and per-tool Retry.

🧬

x64 + ARM64 awarenessArchitecture-specific packages can adapt automatically. Google Chrome now installs the native Enterprise MSI on both x64 and ARM64 Windows Sandbox hosts.

🌐

Browsers ready for testingChrome and Firefox receive Sandbox-friendly policies that suppress first-run, default-browser and promotional flows while keeping private browsing actions one click away.

🛠️

Tool actions that make senseApps get focused Start/Open actions, PsExec exposes SYSTEM shells, and PowerShell 7 can launch as SYSTEM when PsExec is part of the same build.

✅

Release hardeningReproducible npm installs, automated catalog checks, production builds, internal link and anchor validation, security guidance and a Bug Report issue form are now part of the public project.

9 Sep 2026
FEATURES + APPS

Safer builds, better inspection

🔎

Tool detailsEach catalog item now exposes its publisher, download host, install method, architecture, dependencies and public manifest.

🧸

Tool limitBuilds are capped at 20 selected tools, with a heads-up from 15 onward. Automatically added dependencies do not count toward the limit.

🧾

Source inspectorWSB and PowerShell previews are collapsible, syntax highlighted and scrollable, with stable line numbers and optional word wrap.

🔗

Share menuCopy a link or share Build My Sandbox through the native share sheet, X, Bluesky, LinkedIn or email.

🛡️

Safer defaultsNetworking stays required for downloads. Clipboard, host Downloads sharing and optional fixes start disabled unless you choose them.
